TS5 — DDR5 Temperature Sensor

TS5110

Real-time thermal management for next-generation DDR5 systems, designed to prevent overheating and system failures.

Download Product Brief Request Samples

Product Description

TS5110A0 / TS5210A0 device incorporates thermal sensing capability which is controlled and read over two wire bus. TS5 device operate from a nominal 1.8 V nominal power supply (VDDSPD) and a 1.0 V nominal power supply (VDDIO).

The TS5 device is intended to operate up to 12.5 MHz on an I3C Basic bus or up to 1 MHz on an I2C bus. The TS5 devices are intended to interface to I2C or I3C Basic buses which have multiple devices on a shared bus and must be uniquely addressed with fixed addressing on the same bus. All TS5 devices respond to specific pre-defined device select codes on the two-wire bus.

Package Pinout

6 ball WLCSP. Ball pitch 0.5 mm. Package size 0.8 + 0.05 mm x 1.3 + 0.05 mm. Ball diameter 0.22 mm (after ball attach reflow); max package thickness including bump 0.6 mm.

Key Features

— Two wire bus serial interfaces (I2C and I3C Basic operation modes)
— Up to 12.5 MHz transfer rate
— 6 ball WLCSP package device functional diagram
— 1.8 V & 1.0 V power supply input
— Temperature sensor with high accuracy for JEDEC specification compliance
— Temperature range from -40°C to +125°C
— Packet Error Check (PEC) function
— Parity Error Check function
— Bus reset function
— Two unique addresses selected by SA pin
— In Band Interrupt (IBI)
— 5-byte unique serial number to support authentication (TS5210A0 only)

Applications

DDR5 DIMMs for servers (RDIMM, LRDIMM and MRDIMM)
